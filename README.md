Repositorio personal dedicado al estudio práctico de ciberseguridad, recopilando apuntes, metodologías, máquinas resueltas, explotación de vulnerabilidades y conocimientos adquiridos durante laboratorios y cursos especializados.

📌 Descripción

Este repositorio contiene documentación y notas organizadas relacionadas con distintas áreas de ciberseguridad ofensiva y análisis de vulnerabilidades.

Incluye:

🖥️ Writeups y resolución de máquinas de Hack The Box y TryHackMe
🔎 Metodologías de reconocimiento y enumeración
⚔️ Explicación y uso de exploits
📚 Apuntes tomados durante cursos y laboratorios
🛠️ Cheatsheets y comandos útiles
🌐 Técnicas de explotación web
📡 Enumeración de servicios y directorios
🔐 Conceptos de pentesting y seguridad ofensiva

El objetivo principal del repositorio es centralizar conocimientos prácticos y crear una base de consulta rápida para futuros proyectos, laboratorios y evaluaciones de seguridad.

🎯 Objetivos
Documentar aprendizaje práctico en ciberseguridad.
Mantener una base organizada de conocimiento técnico.
Crear referencias rápidas para pentesting.
Registrar metodologías utilizadas en laboratorios reales.
Facilitar el estudio y revisión de conceptos avanzados.
